# Petzy - Pet Care App

Aplicación móvil para conectar dueños de mascotas con cuidadores mediante Clean Architecture y Riverpod.

## Requisitos previos
- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0

## Pasos de ejecución
1. Clonar el repositorio.
2. Ejecutar `flutter pub get` en la terminal para instalar dependencias.
3. Iniciar en emulador o dispositivo real ejecutando:
   ```bash
   flutter run
